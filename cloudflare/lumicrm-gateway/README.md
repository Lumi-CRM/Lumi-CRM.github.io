# LumiCRM Cloudflare gateway

Бесплатный Worker проксирует запросы браузера и приложений к Supabase. Данные и ключи в Cloudflare не сохраняются.

Рабочий адрес: `https://lumicrm-gateway.denzotrail.workers.dev`

Исходник в `worker.js` должен совпадать с кодом Worker `lumicrm-gateway` в панели Cloudflare.
