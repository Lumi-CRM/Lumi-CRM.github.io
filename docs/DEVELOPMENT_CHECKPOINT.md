# LumiCRM — точка продолжения

Дата остановки: 30 июля 2026.

## Состояние

- `npm run lint` и `npm run build` проходят без ошибок.
- Исправленный импорт Google Sheets применён к Supabase.
- В базе: 36 клиентов, 25 объектов, 29 задач, 13 встреч, 68 взаимодействий, 97 исходных строк импорта.
- Из 29 задач 7 находятся в работе/ожидают выполнения, 22 завершены.
- У 59 взаимодействий есть текстовые комментарии.
- Повторяющихся телефонов, точных адресов и близких адресов с опечаткой не осталось.
- «Мирная 4» и «Маирная 4» объединены: один объект, один собственник, пять записей истории.
- Ручные карточки пользователя сохранены; удалены только записи ошибочных запусков импорта.

## Уже реализовано

- История звонков, сообщений и встреч в карточках собственника и объекта.
- Комментарии из таблицы показаны в истории с датами и следующими контактами.
- Документы собственника, объекта и общий архив через приватный bucket `crm-documents`.
- Галерея по папкам объектов и группам помещений через приватный bucket `crm-images`.
- Связь собственника с существующим или новым объектом.
- Сортировка объектов от новых к старым.
- Пять тем оформления; удалён старый отдельный переключатель тёмной темы.
- Исправлены контрастность старых блоков и адаптивная прокрутка приветственного окна.
- Импорт объединяет записи по телефону, имени/адресу, нормализованному адресу и коротким опечаткам в адресе.
- Сквозная загрузка и удаление документа и фотографии реально проверены через Supabase Storage.
- Кириллические имена файлов и папок транслитерируются в безопасные storage keys; ошибка `Invalid key` устранена.
- Все пять тем проверены; меню тем поднято над содержимым и больше не перекрывается поиском.
- Добавлен отдельный раздел `/landlords` и роль `landlord`; аренда и продажа используют разные типы объектов.
- Покупатели, арендаторы, собственники, объекты, задачи и события явно ограничены `user_id` текущего аккаунта поверх RLS.
- При ошибке записи `property_details` новая базовая карточка объекта удаляется, чтобы не оставлять неполный объект.
- Списки собственников/арендодателей и покупателей/арендаторов адаптированы для узких экранов.
- В рабочем Supabase применена миграция `20260730_crm_integrity.sql`: проверка принадлежности связей, автоматический `updated_at`, индексы файлов и заявок. Проверка SQL Editor показала 12 событий триггеров на 4 таблицах.
