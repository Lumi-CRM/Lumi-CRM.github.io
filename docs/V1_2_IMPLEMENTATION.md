# LumiCRM 1.2.0

Статус: разработка в ветке `codex/v1.2.0`.

## Правила релиза

- Стабильная версия 1.1.9 не изменяется до готовности release candidate.
- Изменения схемы сначала проверяются на резервной копии Supabase.
- Старые маршруты сохраняются до завершения миграции интерфейса.
- Каждая стадия должна проходить тесты, линтер и production-сборку.
- Публикация 1.2.0 выполняется только после проверки веба, Android и Windows.

### 2. Единый слой данных

- [ ] убрать прямые запросы к Supabase из страниц;

Первая часть слоя данных готова:

- TanStack Query хранит общее состояние запросов в памяти приложения;
- существующий IndexedDB-кэш остаётся долговременным хранилищем для работы без сети;
- главная, экран «Сегодня», «Контакты», «Объекты», «Задачи», календарь, журнал звонков, сделки, месячный план, архив, избранное и корзина используют общий кэш;
- успешная фоновая синхронизация автоматически обновляет открытые разделы;
- запросы всех перенесённых разделов явно ограничены текущим пользователем;
- значок облака показывает проблемные записи, причину сбоя и число попыток;
- создание и изменение задач сразу отражается на экране, включая работу без сети;
- встречи, звонки, сделки и месячный план используют тот же офлайн-совместимый механизм сохранения;
- списки и формы покупателей, арендаторов, собственников и арендодателей используют единый кэш контактов;
- критерии заявки покупателя и привязка объекта к собственнику сохраняются через общую офлайн-очередь;
- избранное и удаление контактов обновляют интерфейс сразу, без повторной загрузки всей страницы;
- изменения звонков, встреч и сделок обновляют автоматический факт плана;
- восстановление, удаление и очистка корзины сразу отражаются во всех открытых разделах.
